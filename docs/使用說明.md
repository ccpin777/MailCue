# MailCue 使用說明

[English User Guide](user-guide.en.md) · [繁體中文 README](../README.zh-TW.md) · [English README](../README.md)

MailCue 是 Outlook 側邊欄 Add-in。它只會在你按下 **Translate**、**Suggest Reply** 或 **Ask** 時，將目前開啟的郵件或你貼上的文字送去處理；它不會自動掃描信箱，也不會自動寄出回覆。

## 第一次使用

如果 MailCue 還沒有安裝，請先看[繁體中文 README 的初次設定](../README.zh-TW.md#初次設定)。目前專案提供的是原始碼和手動建置流程，並非下載後即可安裝的通用安裝程式；第一次設定需要在 Mac 上準備 Node、建立並信任 localhost 憑證、設定允許使用的 Outlook 帳號，並將 `manifest.xml` 加入 Outlook。建置指令也依賴專案 workspace 中共用的 Python 環境，因此尚未做到一般使用者可直接 clone 後一鍵建置。

安裝完成後，第一次開啟 MailCue 時，請到 Outlook 側邊欄 **Settings**：

1. 確認 **Outlook account** 是目前在 Outlook 開啟的帳號，必要時輸入並按 **Save**。
2. 按 **Connect ChatGPT**，在瀏覽器登入並授權。
3. 選擇 **ChatGPT model**；預設使用模型清單的第一個項目。
4. 在 **Translate to** 確認或更改翻譯語言。預設為 **Traditional Chinese (Taiwan)**，更改後按 **Save**。

選單列 MailCue 需要保持 **Turn On**，Outlook 側邊欄才能連線。

## 日常使用

1. 從 macOS 選單列的 MailCue 圖示打開選單，選 **Turn On**。看到狀態變成 **Turn Off** 代表本機服務已啟動。
2. 在 Outlook 開啟一封郵件，從 Outlook 工具列打開 **MailCue** 側邊欄。
3. 若使用 **Email** 模式，MailCue 會處理目前開啟的郵件。若只想處理一段文字，選 **Selected text**，貼上要處理的內容。
4. 按 **Translate** 翻譯，或按 **Suggest Reply** 產生簡短英文回覆建議。回覆只會顯示在側邊欄，不會自動填入或寄出。
5. 在結果下方輸入問題可繼續詢問，例如要求解釋翻譯或修改回覆。按 **Enter** 送出，按 **Shift+Enter** 換行。
6. 按 **New request** 開始新的工作；它會清除目前結果、對話和 Selected text 輸入內容。

## Settings

按側邊欄右上角的齒輪開啟 **Settings**：

- **Connect ChatGPT**：第一次使用時登入並授權。登入狀態會保存在這台 Mac 上。
- **Outlook account**：輸入允許 MailCue 使用的 Outlook 帳號並按 **Save**。目前開啟的 Outlook 帳號必須與這裡設定的帳號相同。
- **ChatGPT model**：選擇要使用的模型；選擇後會立即儲存並套用。
- **Translate to**：選擇建議語言，或輸入其他語言名稱，再按 **Save**。預設是 **Traditional Chinese (Taiwan)**。

設定和登入資料存放在 `~/Library/Application Support/MailCue`。不要把這個資料夾中的 `config.json`、憑證或登入資料上傳到 GitHub。

## 啟動與關閉

- **Turn On** 啟動 Outlook Add-in 所需的本機服務；使用 MailCue 時需保持開啟。
- **Turn Off** 停止本機服務。停止後，Outlook 側邊欄無法載入或呼叫 MailCue。
- **Launch at Login** 開啟後，MailCue 選單列 App 會在你登入 macOS 時自動啟動。請勿移動已設定登入啟動的 `MailCue.app`。
- **Quit MailCue** 停止服務並退出選單列 App。

如需手動啟動服務，可使用專案中的 `npm_start.command`；使用它時不要同時按選單列 App 的 **Turn On**，因為兩者會使用相同的本機連接埠。

## 修改程式後

若修改了 MailCue 程式碼，需要在 Mac 上執行 `commands/build-menubar-app.command` 重新建立 `dist/MailCue.app`，再啟動新版本。只要 Add-in 的 manifest URL 沒有變更，就不需要重新安裝 Outlook Add-in。這次新增的翻譯語言設定也需要包含在重建後的 App 才會出現在 Outlook。

## 常見狀況

- **側邊欄無法載入**：確認選單列 MailCue 已啟動且狀態為 **Turn Off**。如果本機服務未啟動，選 **Turn On**。
- **This mailbox is not enabled**：在 Settings 將 **Outlook account** 設為目前 Outlook 顯示的帳號並按 **Save**。
- **連接埠已被使用**：確認沒有同時執行選單列 MailCue 和 `npm_start.command`；只保留其中一種啟動方式。
- **翻譯語言沒有更新**：在 Settings 按 **Save**，再開始新的 Translate 請求。
- **模型回報錯誤**：回到 Settings 選擇另一個可用模型後重試。
